# Name to SVG

Type a name, save an SVG image of that name.

## What you need

- Python 3.11+ installed
- A terminal (Command Prompt, PowerShell, or macOS/Linux Terminal)

## Run it

```bash
python generate_svg.py
```

When prompted, type your name. The script writes `name.svg` in the current folder.

## Example output

```text
Enter a name to render as SVG: Ada Lovelace
Saved SVG to name.svg
```
